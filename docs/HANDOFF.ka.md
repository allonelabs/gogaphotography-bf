## 1. დომენი — ყველაზე მნიშვნელოვანი

ახლა კლიენტები ხვდებიან ძველ საიტზე, ან `gogaphotography.ge`-ზე, რომლის
უსაფრთხოების სერტიფიკატი ამოიწურა 27 ივლისს — ბრაუზერი აჩვენებს გაფრთხილებას.
სანამ ეს არ გასწორდება, ახალი საიტი კლიენტებისთვის უხილავია.

**ვარიანტი A — Cloudflare (თუ პაროლი გახსოვს):**

1. შედი <https://dash.cloudflare.com>
2. აირჩიე `gogaphotography.ge` → **DNS**
3. იპოვე `A` ჩანაწერი სახელით `@` და შეცვალე მნიშვნელობა:

```
76.76.21.21
```

4. ღრუბლის იკონა უნდა იყოს **ნაცრისფერი** (DNS only), არა ნარინჯისფერი
5. შეინახე

**ვარიანტი B — cloud9 (თუ Cloudflare-ზე ვერ შედიხარ):**

1. შედი <https://my.cloud9.ge> — შესვლა **ელფოსტით**, არა მომხმარებლის სახელით
   (პაროლის აღდგენა: `my.cloud9.ge/password/reset`)
2. იპოვე დომენი `gogaphotography.ge` → **Nameservers**
3. წაშალე ორივე `cloudflare.com` ჩანაწერი და ჩაწერე:

```
ns1.vercel-dns.com
ns2.vercel-dns.com
```

4. შეინახე

ორივე ვარიანტი მუშაობს — საჭიროა მხოლოდ ერთი. საიტი ჩაირთვება რამდენიმე წუთში
და სერტიფიკატი გამოვა ავტომატურად.

უსაფრთხოა: `gogaphotography.ge`-ს არ აქვს MX ჩანაწერები, ამიტომ ელფოსტა ვერ
გაფუჭდება.

## 2. Messenger და Instagram

აპლიკაცია **GOGA Bot** უკვე არსებობს და ტოკენი მოქმედია. აკლია მხოლოდ ერთი
დაწკაპუნება — გვერდის გამოწერა (subscription).

1. შედი <https://developers.facebook.com> → აპლიკაცია **GOGA Bot**
2. **Messenger** → **Settings**
3. სექციაში **Webhooks** ჩაწერე მისამართი:

```
https://gogaphotography-bf.vercel.app/api/meta/webhook
```

   - Verify token: იგივე მნიშვნელობა, რაც ადმინში წერია (Messages → Settings)
   - მონიშნე ველები: `messages` და `messaging_postbacks`

4. სექციაში **Access Tokens** დააკავშირე სტუდიის Facebook გვერდი და დააჭირე
   **Add Subscriptions**
5. Instagram-ისთვის: **Instagram** → დააკავშირე პროფესიონალური ანგარიში, შემდეგ
   ჩააკოპირე მისი **Instagram user ID** ადმინში (Messages → Settings)

სანამ მე-4 ნაბიჯი არ გაკეთდება, შეტყობინებები ადმინში არ შემოვა — ამიტომაა
რომ დღემდე არც ერთი მიმოწერა არ გამოჩენილა.

## 3. Pinterest — ყველაზე ნაკლებად სასწრაფო

Pinterest-ს პაროლით შესვლა არ აქვს — საჭიროა დეველოპერული აპლიკაცია.

1. შედი <https://developer.pinterest.com> → **Create app**
2. Redirect URI — ზუსტად ასე:

```
https://gogaphotography-bf.vercel.app/api/pinterest/oauth/callback
```

3. Scopes: `boards:read`, `pins:read`, `pins:write`, `user_accounts:read`
4. გაუგზავნე დეველოპერს **App ID** და **App secret**
5. შემდეგ ადმინში დააჭირე **Connect**

10 პინი უკვე რიგშია და დაიდება მაშინვე, როცა კავშირი შეიქმნება.
